# SHRIYA.EXE · studio archive

The flagship gallery of **SHRIYA.EXE**, Shriya Shekatkar's independent creative-technology studio: one original, working application per drop.

**Live → https://shriyashekatkar25-byte.github.io/shriya-exe/**

The page is a single self-contained `index.html`. It asks the GitHub search API for public repositories owned by `shriyashekatkar25-byte` with the topic `shriya-exe`, and renders them as generative tiles (each repo name seeds its own SVG composition), with search, topic filters, a timeline and studio stats. If the API is rate-limited it shows the last copy cached in your browser and links to GitHub. Nothing else is loaded besides Google Fonts.

It updates itself: tagging a new repo `shriya-exe` adds it to the archive.
